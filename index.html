Python Basics

print() · variabel · input() · penamaan

W1S1 · Pemanasan

Apa yang muncul di layar?

print("2 + 3")

🙋 Tebak dulu — siapa berani jawab?

W1S1 · Pembahasan Pemanasan

Tercetak: 2 + 3 — bukan 5!

  • Tanda kutip = Python menampilkan teks apa adanya.
  • Di dalam kutip, 2 + 3 hanyalah tulisan, bukan perhitungan.
  • Mau dihitung? Lepas kutipnya: print(2 + 3) → 5.
W1S1 · Konsep

Dua fondasi pertama

  • print() = pengeras suara Python — tugasnya menampilkan ke layar.
  • Variabel = kotak berlabel: umur = 18 artinya "simpan 18 ke kotak umur".
  • = artinya simpan, bukan "sama dengan". Isi kotak boleh ditimpa.
  • Aturan nama kotak: mulai huruf atau underscore (_), tanpa spasi, bukan keyword Python (if, for, def...). umur_26 ✓ _skor ✓ 2umur ✗ if ✗
W1S1 · True or False #1

Benar atau Salah?

Python is case-sensitive, so age and Age refer to two different variables.
BENARTRUE
SALAHFALSE

🙋 Tangan ke atas — vote dulu, baru kita bahas!

W1S1 · Pembahasan TF #1
BENAR ✔
  • Python membedakan huruf besar-kecil: age, Age, AGE = tiga kotak yang berbeda.
  • Konvensi: nama variabel pakai huruf kecil semua — umur, total_nilai.
  • Kena NameError padahal variabelnya "ada"? Cek dulu huruf besar-kecilnya.
W1S1 · True or False #2

Benar atau Salah?

In Python 3, the expression 10 / 2 produces the float 5.0, not the integer 5.
BENARTRUE
SALAHFALSE

🙋 Hati-hati — ini kelihatan banget "jelas"…

W1S1 · Pembahasan TF #2
BENAR ✔
  • Di Python 3, / selalu menghasilkan float — meski hasilnya "bulat": 10 / 2 → 5.0.
  • Mau hasil bulat? Pakai // = floor division — dibulatkan ke bawah: 10 // 2 → 5, 10 // 3 → 3.
  • Jebakan negatif: -5 // 2 → -3, bukan -2! "Ke bawah" = turun di garis bilangan, bukan "buang angka di belakang koma".
  • Ada float di hitungan? Hasilnya ikut float: 10.0 // 2 → 5.0.
W1S1 · True or False #3

Benar atau Salah?

input() always returns a string until its result is explicitly converted.
BENARTRUE
SALAHFALSE

🙋 User mengetik angka 18 — isinya angka atau bukan?

W1S1 · Pembahasan TF #3
BENAR ✔
  • input() selalu menyerahkan teks — meski user mengetik angka.
  • umur = input("Umur: ") → isi kotaknya "18" (string!), bukan 18.
  • Mau dihitung? Konversi dulu: umur = int(input("Umur: ")) → baru jadi angka.

🙋 Python punya "buku sopan santun" — apa isinya?

Data Types Deep Dive

int · float · str · bool · error types

W1S2 · Konsep

Empat tipe yang wajib hafal

  • int — bilangan bulat: 7, -2, 2026
  • float — desimal, pakai titik bukan koma: 3.14, 0.5
  • str — teks dalam kutip: "Halo" · teks bisa dikali: "ha" * 3
  • bool — kebenaran: True / False (huruf depan kapital!)
  • Iseng ngecek tipe? type(5) · type("hai") · type(3.0)
W1S2 · Pemanasan

Dua baris, satu simbol

print(5 + 3)
print("5" + "3")

🙋 Angkanya sama, kok hasilnya beda?

W1S2 · Pembahasan Pemanasan 
8
53
  • 5 + 3 → dua angka → dijumlah: 8.
  • "5" + "3" → dua teks → ditempel: "53".
  • Simbol sama, perlakuan beda — semuanya tergantung tipe data.
W1S2 · True or False #1

Benar atau Salah?

A Python string can be changed directly with an assignment such as text[0] = 'A'.
BENARTRUE
SALAHFALSE

🙋 Kayak ganti isi kotak biasa… atau bukan?

W1S2 · Pembahasan TF #1
SALAH ✘
  • String itu immutable — tidak bisa diubah lepasan begitu saja.
  • text[0] = "A" → meledak: TypeError ('str' object does not support item assignment).
  • Solusinya: buat string baru lalu timpa: text = "A" + text[1:].
W1S2 · True or False #2

Benar atau Salah?

Calling .upper() on a string changes the original string in place.
BENARTRUE
SALAHFALSE

🙋 Sama keluarganya dengan soal tadi… 😏

W1S2 · Pembahasan TF #2
SALAH ✘
  • .upper() tidak mengubah string lama — dia mengembalikan string BARU.
  • kata = "halo" → kata.upper() menghasilkan "HALO", tapi kata masih "halo".
  • Mau menyimpan hasilnya? Timpa kotaknya: kata = kata.upper().

Conditional Statements

if · elif · else · urutan kondisi

W2S1 · Konsep

Indentasi bukan gaya — itu sintaks

  • Setelah titik dua :, blok kode wajib menjorok (4 spasi).
  • Yang menjorok = milik if · yang lurus = di luar if, jalan terus.
  • = menyimpan nilai · == membandingkan ("sama nggak?").
  • Ekspresi perbandingan menghasilkan True / False. Tapi if juga bisa nerima nilai biasa: if 1: jalan (truthy) · if 0: skip (falsy).
W2S1 · Pemanasan

Lulus atau remedial?

nilai = 75

else:

🙋 Perhatikan tanda >= baik-baik…

W2S1 · Pembahasan Pemanasan

Lulus!

  • >= artinya "lebih besar atau sama dengan" → 75 ikut lolos.
  • Kondisi True → jalankan blok if · False → lompat ke else.
  • Batas halus: > 75 vs >= 75 bisa mengubah nasib nilai 75!

Loops & Iterations

for · while · range · continue/break

W2S2 · Konsep

for vs while — kapan pakai apa?

  • for — "ulangi sebanyak N kali" → jumlahnya sudah pasti.
  • while — "ulangi selama masih True" → jumlah putaran tak pasti.
  • while butuh 3 sahabat: mulai (i = 0), cek (i < 3), ubah (i += 1).
  • Lupa sahabat ketiga? Loop-nya abadi. (Stop pakai Ctrl + C.)
W2S2 · Pemanasan

Berapa kali, dan mencetak apa?

for i in range(3):
    print(i)

🙋 Hati-hati… jebakan klasik pemula 😈

W2S2 · Pembahasan Pemanasan 
0
1
2
  • range(3) = 0, 1, 2 — mulai dari 0, berhenti sebelum 3.
  • Angka stop tidak ikut! Ingat baik-baik — soal berikutnya nyambung.
W2S2 · True or False #1

Benar atau Salah?

for i in range(1, 5) will iterate the numbers 1, 2, 3, 4, 5.
BENARTRUE
SALAHFALSE

🙋 Ingat pemanasan tadi — angka stop ikut atau nggak?

W2S2 · Pembahasan TF #1
SALAH ✘
  • range(1, 5) = 1, 2, 3, 4 — angka stop tidak ikut.
  • Mau sampai 5? Tulis range(1, 6).
  • Hafalan: range(start, stop) → start ikut, stop tinggal.
W2S2 · True or False #2

Benar atau Salah?

The continue statement skips the rest of the current iteration and jumps to the next one.
BENARTRUE
SALAHFALSE

🙋 "Skip" itu artinya berhenti total, atau…?

W2S2 · Pembahasan TF #2
BENAR ✔
  • continue = "skip putaran ini, gas langsung ke putaran berikutnya" — loop tetap jalan.
  • Contoh: range(5) + continue saat i == 2 → tercetak 0, 1, 3, 4.
  • Pasangannya break = "hentikan loop sekarang juga" — ganti break di posisi yang sama → cuma 0, 1.
  • Hafalan: continue = skip satu · break = kabur habis.
W2S2 · Tebak Output

Berapa totalnya?

total = 0

Totalnya 10

  • range(1, 5) → 1, 2, 3, 4.
  • total += i = total = total + i → 0 → 1 → 3 → 6 → 10.
  • Ini pola akumulator: kotak dibuat sebelum loop, diisi di dalam, dibaca setelah.
  • Hafalkan pola ini — soal isian nanti pakai exact pola ini.

W2S2 · Pembahasan Isian #1

Jawaban: % 10 dan // 10

def sum_of_digits(num):
    total = 0
    while num > 0:
        digit = num % 10      # sisa bagi 10
        total += digit
        num = num // 10       # buang digit terakhir
    return total
  • num % 10 → sisa bagi 10 = digit terakhir. 123 % 10 → 3.
  • num // 10 → buang digit terakhir. 123 // 10 → 12.
  • num = 0 → while gagal langsung → return 0 — benar, jumlah digit 0 memang 0.
  • Num negatif → juga 0, nggak bermakna. Kontraknya: khusus bilangan positif — atau tambah num = abs(num).

  • continue skip satu putaran · break bunuh loop.

Function Fundamentals

def · parameter vs argumen · return

W3S1 · Konsep

Anatomi sebuah fungsi

  • def = menyimpan resep. Memanggil sapa() = memasak. Membuat mesin ≠ menjalankan mesin.
  • Yang di dalam kurung def = slot input · yang dimasukkan saat dipanggil = nilai nyata.
  • return hasil = nilai keluar dari mesin, bisa langsung dipakai: dua_kali(5) + 1 → 11.
  • Tulis sekali, panggil sebanyak apa pun — gunanya fungsi.
W3S1 · Pemanasan

Apa yang muncul di layar?

def sapa():
    print("Halo!")

🙋 Perhatikan: tidak ada baris lain. Tetap ada yang muncul?

W3S1 · Pembahasan Pemanasan

Tidak ada apa-apa. Sunyi senyap.

  • def hanya menyimpan resep — belum memasak apa-apa.
  • Resep jalan saat dipanggil: sapa() → baru "Halo!" tercetak.
W3S1 · True or False #1

Benar atau Salah?

'Parameters' are the actual values passed in when a function is called, while 'arguments' are the placeholder names in the function header.
BENARTRUE
SALAHFALSE

🙋 Baca pelan dua definisinya — ada yang aneh nggak?

W3S1 · Pembahasan TF #1
SALAH ✘ — definisinya tertukar!
  • Yang benar: parameter = placeholder di header fungsi: def sapa(nama) → nama parameternya.
  • Argumen = nilai nyata saat dipanggil: sapa("Rina") → "Rina" argumennya.
  • Jembatan keledai: Parameter di dPefinisi · Argumen saat pemanggilAan (aksi).
W3S1 · True or False #2

Benar atau Salah?

A return statement immediately ends the function, so any code written after it in the same block never runs.
BENARTRUE
SALAHFALSE

🙋 return itu "kirim hasil" atau "pintu keluar"?

W3S1 · Pembahasan TF #2
BENAR ✔
  • return = pintu keluar: begitu kena, fungsi langsung selesai.
  • Bukti: def contoh(): → return 1 lalu print("muncul nggak?") di bawahnya → teks itu tidak pernah tercetak.
  • Justru berguna: keluar lebih awal — if gagal: return False.

W3S1 · Isian Program #2

Rancang konverter suhu yang modular

Design a modular temperature converter using convert_c_to_f(), convert_f_to_c(), and main(). Explain the division between business logic and user-interface logic in your design.
°F = (°C × 9/5) + 32
°C = (°F − 32) × 5/9

🙋 Rancang dulu di kertas — fungsi mana yang boleh input/print?

W3S1 · Pembahasan Isian #2 — Kode

Tiga fungsi, tiga tugas

def convert_c_to_f(c):
    return c * 9 / 5 + 32

def convert_f_to_c(f):
    return (f - 32) * 5 / 9

def main():
    arah = input("Konversi ke? (f/c): ")
    suhu = float(input("Suhu: "))
    if arah == "f":
        hasil = convert_c_to_f(suhu)
    else:
        hasil = convert_f_to_c(suhu)
    print(f"Hasil: {hasil}")

main()
W3S1 · Pembahasan Isian #2 — Konsep

Dua dunia yang dipisah rapi

🧮 Business Logic

convert_c_to_f & convert_f_to_c — murni matematika, hanya return. Tanpa input/print → gampang dites, gampang dipakai ulang di program lain.

🖥️ User-Interface Logic

main() — urusan percakapan dengan user: input, output, alur percabangan. Panggil fungsi bisnis, tampilkan hasilnya.

  • Prinsip: satu fungsi, satu tugas. Ganti tampilan? Sentuh main() saja — rumusnya aman.
W3S1 · Recap

Yang wajib nempel di kepala

  • return = pintu keluar — kode setelahnya di blok yang sama tak pernah jalan.
  • Fungsi tanpa return balik None · print ≠ return.
  • Parameter di definisi, argumen di pemanggilan · default harus di belakang.
  • Pisahkan business logic (return) dari UI (input/print).

Scope & Modules

global vs local · import random

W3S2 · True or False #1

Benar atau Salah?

A variable created inside a function can be read normally from outside that function after the function finishes.
BENARTRUE
SALAHFALSE

🙋 Fungsinya selesai, variabelnya masih hidup atau sudah dibersihkan?

W3S2 · Pembahasan TF #1
SALAH ✘
  • Variabel local lahir dan mati di dalam fungsinya.
  • def buah(): → buah = "mangga" → selesai dipanggil, buah sudah tak ada → print(buah) meledak NameError.

  • Analogi: global = papan pengumuman sekolah · local = catatan di kamarmu.
  • Fungsi yang sehat bicara lewat parameter & return — bukan mencuri variabel orang.

W3S2 · Pembahasan PG #2

W3S2 · Konsep

Modul = fitur siap pakai

  • import math = pinjam kotak perkakas bawaan Python, pakai lewat titik: math.sqrt(16) → 4.0.
  • Males nulis titik? from random import randint → panggil randint(1, 6) langsung.
  • Prinsip programmer: kalau sudah ada, jangan tulis ulang.
  • ⚠️ Jangan namai file-mu math.py atau random.py — Python bisa "salah pinjam" ke file-mu sendiri!
W3S2 · Recap

Yang wajib nempel di kepala

  • Variabel local lahir & mati di fungsinya — keluar lewat return.
  • Assignment di dalam fungsi = local baru, bukan mengubah global.
  • random untuk dadu & shuffle · randint(1, 6) → 6 ikut.
  • Jangan tabrakan nama file dengan nama modul.
